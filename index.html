📐 গণিত ও বিজ্ঞান সূত্র ভান্ডার (Formula Hub)

বীজগণিত (Algebra)

• (a + b)² = a² + 2ab + b²

• (a - b)² = a² - 2ab + b²

• a² - b² = (a + b)(a - b)

• (a + b + c)² = a² + b² + c² + 2(ab + bc + ca)

• a³ + b³ = (a + b)(a² - ab + b²)

• a³ - b³ = (a - b)(a² + ab + b²)

ত্রিকোণমিতি (Trigonometry)

• sin²θ + cos²θ = 1

• sec²θ - tan²θ = 1  |  cosec²θ - cot²θ = 1

• tanθ = sinθ / cosθ  |  cotθ = cosθ / sinθ

• sin(90° - θ) = cosθ  |  cos(90° - θ) = sinθ

জ্যামিতি ও পরিমিতি (Mensuration)

• ত্রিভুজের ক্ষেত্রফল = ½ × ভূমি × উচ্চতা

• বিষমবাহু ত্রিভুজ = √[s(s-a)(s-b)(s-c)], যেখানে s = (a+b+c)/2

• সমবাহু ত্রিভুজের ক্ষেত্রফল = (√3 / 4) × a²

• বৃত্তের ক্ষেত্রফল = πr²  |  পরিধি = 2πr (π ≈ 3.1416)

• সিলিন্ডারের আয়তন = πr²h  |  বক্রতলের ক্ষেত্রফল = 2πrh

পদার্থবিজ্ঞান (Physics)

• গতি: v = u + at  |  s = ut + ½at²  |  v² = u² + 2as

• নিউটনের গতিসূত্র: F = ma  |  ওজন: W = mg (g = 9.8 m/s²)

• গতিশক্তি: Ek = ½mv²  |  বিভব শক্তি: Ep = mgh

• কাজ: W = Fs  |  ক্ষমতা: P = W / t

• ওহমের সূত্র: V = IR  |  রোধের ক্ষমতা: P = VI = I²R

রসায়ন (Chemistry)

• মোল সংখ্যা: n = w / M = V / 22.4L = N / NA (NA = 6.023 × 10²³)

• মোলারিটি: S = (1000 × w) / (M × V(mL))

• বয়েলের সূত্র: P₁V₁ = P₂V₂  |  চার্লসের সূত্র: V₁/T₁ = V₂/T₂

• আদর্শ গ্যাস সমীকরণ: PV = nRT (R = 0.0821 L·atm/mol·K)
